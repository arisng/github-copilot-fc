    Machine schema

    A minimal, deterministic JSON schema for finite state machines. Guards and actions are declarative — there is no code evaluation — so a machine is safe to share, paste, version, and ingest. Concepts are compatible with SCXML and XState.

    FieldTypeMeaning
    idstringStable machine identifier.
    namestringHuman-readable label.
    versionstringMachine's own version (distinct from spec_version).
    initialstringDefault initial state key.
    contextobjectInitial extended state (the default initial conditions).
    scenarios[]arrayNamed entry points. Each overrides initial and context: { id, label, initial?, context?, interface? }, where interface ∈ UI · API.
    statesobjectKeyed by state id: { type?, description?, entry?, exit?, on? }.
    state.type"atomic" | "final"Terminal states are final.
    state.onobjectEvent map: { EVENT: { target, guard?, actions?, description? } }.
    actionobject{ type: "assign", key, value } or { type: "increment", key }.
    guardobject{ type: "compare", key, op, value }. op ∈ eq · neq · lt · lte · gt · gte. A string value resolves against context.
    coverageobjectOptional analysis metadata: metrics, state_coverage, edge_coverage, uncovered_paths, recommendations. Drives the coverage matrix and cycle analysis.
    cycle_preventionobjectOptional guards against infinite loops: max_retry_limit, timeout_seconds, and declarative guards — an array of { event, guard, else_target }.

    Conventions

    Event names UPPER_SNAKE · state keys kebab-case · values may reference context keys by name.
